ROCKS 2.5 — The Final Reveal

Automatic 30-second cinematic rock elimination draw. Includes the user-selected original soundtrack under assets/audio/rocks-cinematic-30s.mp3. Sound is on by default and can be toggled. The application uses unbiased cryptographic randomness and preserves outcomes on replay.

Deploy the entire directory structure to GitHub Pages. Open index.html to test locally. See SOUNDTRACK-SETUP.md.
